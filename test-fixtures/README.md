# 测试固件说明

| 文件 | 格式 | 说明 |
|------|------|------|
| `中文示例_docx_01.doc` | Word 97-2003（CFB） | 由本人自制的 OOXML 示例文档转换生成 |
| `中文示例_pptx_01.ppt` | PowerPoint 97-2003（CFB） | 由本人自制的 OOXML 示例演示文稿转换生成 |
| `中文示例_xlsx_01.xls` | Excel 97-2003（BIFF/CFB） | 由本人自制的 OOXML 示例表格转换生成 |

**来源与版权**：三个文件均为仓库使用者本人制作的中文示例文档转换而来，
**不含任何第三方版权内容**（用户确认，2026-11-24），允许随本仓库提交与分发。
文件名中的 `docx/pptx` 字样指示转换来源，文件本体均为旧版二进制格式
（魔数 `D0 CF 11 E0 A1 B1 1A E1` 已校验）。

**用途**：M4/M5 阶段的渲染验证与宿主端到端验收素材（含「OOXML 转换源」
这一真实场景）。转换生成的旧格式文档天然适合验证：
- `.doc`：文档正文结构还原
- `.ppt`：由演示文稿转换的逐页内容
- `.xls`：表格数据与公式缓存值

**补充的降级测试样例**（损坏/伪装文件，M4 由脚本生成）不随 git 提交。
